# 2026-10-11 딜러 공개 연출 속도 조정

## 시작

> 3번에서도 이미 애니메이션을 바꿔주긴 했는 데... 애니메이션 재생 조금 손 대고 싶어서 메모 연락 남김
>
> 1. 딜러의 히든 카드 오픈 애니메이션은 현재의 50%~60% 정도 시간 안에 완료되어도 될 것 같음(지금보다 두 배 빠르게?)
> 2. 딜러의 히든 카드 오픈 후, 17에 도달하지 못하여 새 카드를 받을 때 현재 히든 카드 오픈 시간의 절반의 시간을 투자하여 '카드 뒷면 배포', 그 후 현재 히든 카드 오픈 시간의 절반을 다시 투자하여 '카드 뒤집기' 순으로 애니메이션이 재생되면 좋겠음.

- "3번"은 PR #3(딜러 홀 카드 공개 연출)으로 해석. 이전 결정 [`2026-10-11-ui-feel.md`](2026-10-11-ui-feel.md)#사용자가 명시하지 않아 에이전트가 정한 것 "딜러 공개 타이밍"(뒤집기 950ms, 추가 카드 800ms 간격·0.45s 앞면 딜)을 **뒤집음**. 대상과 값이 명확해서 확인 없이 적용.
- "현재 히든 카드 오픈 시간" = 950ms → 절반 475ms.

## 사용자가 명시하지 않아 에이전트가 정한 것

| 항목 | 정한 값 | 이유 |
|---|---|---|
| 홀 카드 뒤집기 시간 | 475ms (기존 950ms의 50%) | 요청 범위 "50%~60%", "두 배 빠르게?"에 맞음. 2번의 추가 카드 뒤집기(475ms)와 같은 길이라 CSS `.flip` 하나로 공유 |
| 추가 카드 뒤집기 모양 | 홀 카드와 같은 연출(살짝 들어 올렸다가 뒤집기) | 별도 지시 없음. 같은 "카드 뒤집기"로 해석 |
| 뒷면 배포 → 뒤집기 사이 | 쉬지 않음 | 요청 문장이 "그 후" 바로 이어지는 순서로 읽힘 |
| 추가 카드 사이 간격 | 뒤집기 끝 → 다음 카드 뒷면 배포까지 300ms (신규) | 기존 800ms 간격에서 애니(0.45s)를 뺀 휴식이 약 350ms였음. 장당 시간이 이미 950ms로 늘어서 조금 줄임 |
| 홀 카드 공개 후 첫 추가 카드까지 | 450ms 유지 | 요청 범위 밖 |
| 공개 전 대기(550ms/딜 직후 1000ms), 결과까지(400ms) | 유지 | 요청 범위 밖 |
| 합계 갱신 시점 | 추가 카드도 뒷면 동안·뒤집는 동안은 이전 합계, 다 뒤집은 뒤 갱신 | 홀 카드와 같은 규칙 |
